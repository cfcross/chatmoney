# Intelligent_Marketing

Healing-Fun 的营销工作台使用 ChatMoney 共享引擎。ToB 成员处理企业研究、销售咨询和报价交接，ToC 成员处理店铺客服。两条业务线共用会话、知识、政策检查、执行记录和人工接管机制。

## 功能与进度

| 能力 | 在本分支可用的范围 |
|---|---|
| 助手与资料 | 成员按产品创建助手、选择个人模型、绑定已批准资料、测试草稿并发布。已发布版本与知识快照保留历史。 |
| 处理来信 | 引擎结合会话记忆和知识生成回复，检查业务规则，记录模拟渠道回执。正式报价等场景转交人工。 |
| ToB 企业研究 | 助手通过对练和人工审核后，可以申请指定来源的只读权限。研究报告包含证据，成员审核后保存线索。 |
| 团队管理 | 中文工作台提供运行总览、成员、助手、资料、客户会话与任务、人工接管。数据库执行租户隔离，写请求使用幂等键。 |
| ToC 业务准备 | 数据收集、意图覆盖矩阵、政策树、知识缺口和话术评测仍在推进。开发用订单与商品来自模拟数据。 |

真实渠道接入须独立授权。团队禁止滥发、虚构身份及未经授权使用真人形象或音色。

## 参与协作

[路线图](docs/ROADMAP.md)记录阶段、验收条件与缺口。[协作约定](AGENTS.md)列出环境准备、维护分工与工作规则。引擎内核的接口及数据格式变更应先提议讨论。项目级验证手册和 ToC 数据接入约定在 [.agents/skills](.agents/skills)。
