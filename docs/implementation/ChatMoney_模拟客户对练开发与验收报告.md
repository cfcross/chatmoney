## 做成了什么

- 系统模板、个人模板、空白创建都复用现有助手。可测试保存过的草稿或已发布版本；快照固定角色、规则、模型引用、产品和资料版本。不会自动发布。
- 每次对练有一位虚构客户。该客户根据对方实际答复作反应；只有相关提问才允许逐步披露私有设定。销售方只读正常对话。可在修改后复用相同虚构客户，从空记忆重新测试。
- 销售方使用原来的 LangGraph 工作流、关键词检索、模型适配器和业务策略。用同一条客户消息做对照测试：能检索到资料时，两条路径给出相同回复；找不到且无其他依据时，两边均只留草稿。模拟客户不会把草稿当作已收到的回复。
- 支持自动、下一轮、暂停、继续、结束。后台持久记录已发起和已完成的模型调用。中断后不重复调用已有结果；结果不明时停止。真实模型模式收费提示覆盖双方，以及可选的独立评阅；Mock 明示不产生模型费。
- 模拟交接显示触发原话和原因，不创建正式工单。所有者可逐轮看资料、证据和意见，认可或要求修改。对应快照可提交给有发布管理权限的审核员。审核推荐也只到“待平台授权”，不会获得真实工具或发送权。
- 历史记录按稳定位置翻页；对照区也能读更早记录。更新草稿不会替换历史快照，读取或刷新页面不会启动模型。

## 验收证据

| 验收项 | 实际执行和结果 |
|---|---|
| 原有回归 | 将开始前备份与现目录逐字节比较，原 `tests/` 中 24 个 Python 测试及辅助文件全部未变。最终完整运行 **163 passed in 79.38s，0 失败，0 跳过**：原有 127 项 + 新增 36 项。覆盖个人连接、模板与空白创建、资料发布、报价人工交接、O7/O8 订单归属、任务恢复、登录与权限。 |
| 模型与上下文 | 在隔离库用成员本人的测试密钥和模拟 HTTP：客户、销售方分析、销售回复、独立质量评阅使用同一合法模型；另一个成员和管理员不能发起其私有对练或查看全文。检查实际请求体中客户隐藏预算不进入销售上下文，销售指令不作为客户的系统输入。 |
| 费用与恢复 | 并发点击只推进一次；暂停或停止遇到在途调用不发起下次调用。用新的 Worker 继续和模拟遗留预留记录，验证缓存重用、未知即停、超时与用量/轮数上限。 |
| 吴姐规则 | 对正式报价、真人、退订、明确拒绝、禁用工具、未经批准的数值承诺、具体资质、客户联系方式等输入检查实际交接、阻止结果和轮次。安全拒绝和实际越权执行分别记载。硬规则问题不能靠人工勾选或高质量评分消除。未出现或无法机械判断的行为不作通过证明。 |
| 正式数据隔离 | 比较模拟前后的正式客户、订单、对话、记忆、任务、消息、运行、发送、工单等记录；模拟工具不进入真实出口。测试资料被撤回后停止。 |
| 1 GB 上传回归 | 在另建、本机可丢弃的库实际上传。1,000,000,000 字节返回 202，完整下载后 SHA-256 相符；1,000,000,001 字节被拒（413）。Edge 实际检查上传、原文翻页、批准和发布。没有在生产库压测。 |
| 本机 Edge | 真实 Edge + HTTPS 测试工作台 + 独立对练 Worker。跑通下列五条业务流程，并查后台保存的记录。设置页和结果页在 **1440×900、1280×720、1024×768、390×844** 检查无页面横向溢出、操作区按钮重叠或未处理的前端异常。 |
| 公网 Edge | 在最终公网镜像用临时独立测试身份登录；从软件销售模板建未发布草稿，明确选 Mock、绑定已批准的测试资料。第一轮回复确有设置的角色和资料，第二轮因正式报价发生模拟交接，无报价回复。刷新后仍可审阅并提交候选。核对前端资源与本地逐字节一致，未登录候选接口为 401；退出后清理本轮专用测试数据。 |

**五条本机浏览器流程：** ① 模板 → 本人模型（模拟 DeepSeek HTTP）和批准资料 → 保存草稿 → 双方真实经过模型适配器和工作流，多轮、暂停、继续、结束；② 软件销售助手遇到正式报价，保留原话并模拟转人工；③ 冷淡客户逐轮回应、明确拒绝即停；④ 修改草稿再练，比较新旧快照；⑤ 审阅提交后等待授权，审核员可退回变更的候选。另查证可选模型意见确实引用销售原话、复用同一客户时不带旧聊天、历史翻页、模型超时提示、成员隔离和缓存刷新。

开发中纠正了两处会影响结论的差异：模拟不能在普通收件检索失败时额外取产品概览；客户不能把销售回复里单纯提到“场景”误作询问而披露需求。修复后重新跑完整回归和浏览器流程。本机临时 HTTPS 测试日志里偶有 Windows 连接关闭提示（WinError 10054）；浏览器断言、脚本退出码 0 和公网操作结果已分别核对。

## 尚未验证或尚未接入的部分

真实付费 DeepSeek 的自然度、对行业术语的理解、长期模型费用没有用真实密钥实测。自动规则可发现具体违例，不能完整证明所有产品描述、身份陈述和语气都合适。模型评阅是辅助意见，Mock 对练只验证工程路径。没有完整事实匹配或证据不足时，仍需人工核对。

没有真实外联、店铺、退款、采购、改价或直播操作；没有成交概率模型。下一步可单独评审 `company.profile_read` 只读企业工具：先约定获准来源、企业归属、只读字段和证据，再为对练提供虚构返回，验证通过后才讨论正式授权。本轮没有开发该工具，也没有提交或推送 Git。
