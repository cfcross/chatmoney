# ChatMoney 中文管理工作台使用指南

打开团队管理工作台。第一次使用的顺序为 **准备资料 → 创建助手并选模型 → 保存草稿 → 模拟客户对练 → 审阅对应配置 → 单独发布，按已有权限使用**。登录账号决定你能看到的企业、产品和按钮。

## 用销售助手研究一家企业（V1.4）

管理员在「研究来源与授权」登记许可后，把来源编号交给申请人。普通成员在本人的助手中填编号申请。审批通过后，可以选择该版本获准的来源、查看网址范围与有效期。许可原文仅在管理视图展示。同站已有研究时，后台会等待并继续原任务。

在团队工作台中，从 **助手管理 → 本人的销售助手 → 企业研究** 进入。你需要提供一个已经获准研究的官网网址。首次使用，由管理员登记来源；工作台不会替你搜索全网、登录店铺或联系对方。

| 谁来做 | 在哪里点 | 完成后会发生什么 |
|---|---|---|
| 管理员 | 助手管理 → **研究来源与授权 → 登记许可来源** | 填准确网址、许可依据、允许的用途和保留天数。只获准阅读而不能保存摘录的来源，本版不能用。演示选“仅测试验收”；允许交给外部模型处理、记录官方合作页面，都要另有许可 |
| 助手创建者 | 从空白、系统或个人模板创建销售助手；**角色设置**选本人模型，**资料和工具**选已发布的产品资料，勾选 **企业官网资料研究** | 勾选只表示这版助手需要工具。接着保存草稿、模拟对练、查看结果并提交启用审核；另行发布同一份配置 |
| 审核人 | 助手管理 → **启用审核 → 记录审核意见** | 确认对练过的版本可进入待授权阶段。没有授予任何网站权限 |
| 助手创建者／管理员 | 成员在助手详情点 **企业研究 → 申请启用企业研究工具**，选择来源；管理员到 **研究来源与授权 → 批准只读** | 只对这一位成员、这位助手的已发布版本和这个来源有效。更换版本须重新核验；不能用别人的模型额度 |
| 助手创建者 | 在 **企业研究** 选择已批准来源，填网址、研究目标、匹配维度、目标词和权重，点 **开始企业研究** | 后台开始读取。可以离开页面，稍后从 **我的研究记录** 打开。已受理不表示读到了资料。若使用个人 DeepSeek，需另行确认费用及来源的外部模型处理许可 |
| 助手创建者 | **查看研究结果**，核对出处，改写草稿，再点 **审核通过并保存草稿** 或 **标记需要修改** | 审核通过后，再点 **保存为待跟进线索**；验收用途只能 **保存为测试线索**。刷新后仍可查看。两个按钮都不会发送消息 |

**怎么读结果？** 企业名称与“网站署名”分开；只有官网声明产品，不等于该企业正在采购。每个有依据的判断都可回看原句和网页。比如，明确命中“储能柜”可支持产品匹配；未披露预算就保持未知。**证据覆盖率**说明有多少判断条件得到了支持；资料稀少时应同时核查已知条件和覆盖率。即使匹配分为 100，也只表示设定条件匹配，不能解释成 100% 成交。没找到官方商务入口时不要猜邮箱，找到入口也不代表允许营销。

**如何停止和处理失败？** 在执行进度点 **停止研究**，已经发出的读取或模型费用无法撤回。点开 **查看执行记录** 分清是网址不在范围、网站禁止、资料已撤回，还是网络超时。通知管理员核对许可或修改网址；不要用别的浏览器绕过限制。对于可重试的失败，确认条件后点 **重新研究**，会生成新任务，模型有可能再次收费。管理员还可撤销单个助手授权，或 **撤回来源** 并清除该来源留存的研究内容。其他成员（包括管理员）不能打开你的私有研究报告。

产品消息渠道仍是模拟的。明确选用模拟模型时，**研究页面可以发生真实的只读网页请求**；“模拟客户对练”本身不会访问外网。研究资料的使用期限及范围按管理员登记的许可执行。技术细节与测试见[首个真实工具验收报告](ChatMoney_首个ToB真实工具开发与验收报告.md)。

## 保存草稿后，先找一位模拟客户试聊

1. 在「助手管理」选择常用模板、个人模板或从空白创建。填好角色，选择本人的模型，以及业务必需的已批准产品资料。点 **保存草稿并对练**。已经保存的助手从详情点 **模拟客户对练**；无需先发布或创建任务。
2. 选择「当前草稿」或「已发布版本」。系统推荐一类虚构客户，也可改选普通意向、谨慎采购、预算敏感、态度冷淡、高意向或边界测试。比如选“预算敏感”，看助手会不会在客户要求正式报价时转人工。
3. 选逐轮或自动，点击 **开始模拟客户对练**。模拟客户和销售助手使用这位助手已经绑定的同一条个人模型连接，不再填密钥。使用 DeepSeek 需确认费用；可选的逐轮质量评阅也会消耗额度。选 Mock 时是确定性的流程演示，不代表真实对话质量。
4. **下一轮**只进行一个来回；**开始自动对练**连续推进；**暂停**不再启动新的调用，**继续**沿用之前的方式。默认最多 8 轮，在高级设置可调整。点 **结束模拟并查看结果**保留已完成的记录。已发出的模型请求可能收费，刷新页面不会重做一轮。
5. 在「双方对话」查看客户原话、实际回复和本轮参考资料。看到“模拟转人工”，表示这次对练已经停下，没有给吴姐创建真实客户工单。若只生成草稿，页面会标明，模拟客户也不会收到。
6. 看「评测结果」里的轮次、原话、原因和建议。后端规则、模型意见和需人工复核的事项分开显示。模拟没有发生的情形仍然没有测试；这份记录不是成交概率。模型出错时保留之前的对话，不会自动换密钥或重试扣费。
7. 需要改进时，点 **修改助手**，保存后再练。想公平比较，可在上次记录点 **用同一客户重练**，沿用相同的虚构背景，但聊天和记忆从头开始。在新记录最下方选择上一份记录，点 **对照结果**。也可从对练设置页进入历史；记录较多时点 **加载更早记录**，比较区也可加载更早的对照记录。
8. 满意后点 **我已查看本次模拟结果**，记录判断和意见，再点 **提交正式启用审核**。提交只针对显示的配置快照。审核员在「助手管理 → 启用审核」记录推荐或退回；通过仍为 **待平台授权**。发布助手是另一步操作。没有真实适配器、官方账号授权、工具许可和停发控制，不能联系真实客户。

只有助手创建者可看自己的对话全文；管理员审核候选只看到必要摘要。模拟不会修改真实客户记忆、订单或平台权限。操作证据与已知限制见[对练验收报告](ChatMoney_模拟客户对练开发与验收报告.md)。

**第一次使用 DeepSeek**，管理员和普通成员都用自己的账号进入“助手管理 → 创建助手 → 角色设置”。在“使用的模型”选择 DeepSeek，点“添加 DeepSeek 连接”，填连接名称和模型密钥，再点“保存并测试连接”。看到“连接可用”后完成向导并发布。以后自己创建的多个助手可直接选择这条连接。每位成员各自添加密钥，管理员的连接也只对管理员本人可见。需要首次信任本机证书、换密钥或排查错误时，参阅[配置与启动指南](ChatMoney_企业模型连接与DeepSeek配置指南.md)。

## 1. 在一个工作台开账号、改密码、创建助手

1. **首次设置管理员**。在运行 ChatMoney 的电脑上，双击项目根目录的 `打开ChatMoney.cmd`。浏览器会打开设置页。把预填的账号改成你想用的名字（可以用中文），输入至少 12 位的密码，再输入一次确认。以后双击同一个文件即可打开登录页。
2. **给成员开户**。管理员在左侧点“成员账号 → 添加成员”，直接输入账号和密码，点“确认发放”。将这两项私下交给本人。吴姐也可以点成员旁的“允许开通账号”，让指定组员代为发号。
3. **成员创建助手**。成员登录后点“助手管理 → 创建助手”，填写名称和角色，先保存草稿。发布时选一份管理员已批准的产品资料。每人可创建多个助手。普通成员只看到自己的助手和任务。管理员能看到团队全部助手。
4. **改自己的账号或密码**。点“我的账号 → 修改账号和密码”，输入当前密码。可以只改账号，或再填新密码。点“保存修改”，用新信息重新登录，原来的助手仍在。
5. **成员忘记密码**。发号人在“成员账号”找到该成员，点“修改账号和密码”。填新密码后通知本人。只改登录名时将新密码留空。旧的登录会话在保存后失效。
6. **删除成员账号**。管理员打开“成员账号”，找到该成员，点“删除成员账号”并确认。该成员所有设备上的登录同时失效。管理员可以查看或停止其原有的助手和任务。该账号失效后，后台也会阻止后续个人模型调用。重新使用相同的登录名开户，会得到一个新的成员身份。

| 工作台操作 | 管理员 | 普通成员 |
|---|---|---|
| 建库、编辑文件、批准发布、删除资料 | 管理授权产品下的资料及文件 | 可查看、引用已发布资料 |
| 创建、查看、编辑、删除助手和任务 | 管理团队的助手和任务 | 管理自己创建的助手及其任务 |
| 删除成员账号 | 可删除本团队普通成员，包含获授权代发账号的成员 | 此项权限仅授予管理员 |
| 添加、测试、轮换 DeepSeek 连接 | 仅限自己的连接 | 仅限自己的连接 |
| 启动真实模型任务 | 使用自己创建的助手和连接 | 使用自己创建的助手和连接 |
| 修改自己的账号或密码 | 可以 | 可以 |

团队成员用自己的账号进入公网工作台，无须选择企业或开启开发者电脑。上面的双击安装步骤和本机工作台仅适用于独立的本地安装。甲、乙企业来自历史演示。

## 2. 运行总览

上方统计分别是可见助手数量、运行中任务、等待中任务、待认领或正在人工处理的会话。点击数字可进入相应列表。“最近执行”可以点开，查看一次运行做了什么、有没有外发。

右上角“消息渠道 · 模拟环境”说明消息仍发往模拟渠道。每位助手的模型请在“助手管理 → 详情”查看。模型使用授权跟随助手创建者的账号。后台进程暂缺实时心跳。如果任务长时间停在“已排队”，请维护者检查进程。

## 3. 上传并批准企业与产品资料

1. 管理员打开“企业与产品资料库 → 新建资料库”。从“成员账号”首页也可直接点“管理资料库和文件”。选产品，填一个能识别用途的名称，例如“排班产品功能与服务范围”。
2. 进入资料库，点“上传资料”。填文件名称和来源，选择 UTF-8 的 `.txt` 或 `.md` 文件，单文件最大 1 GB（1,000,000,000 字节，含 BOM）。上传时可点“取消”。已收到受理回执时可刷新查看解析状态。解析完成后，管理员核对原文，再批准并发布。
   原文完整保留。超过 2 MB 时仅前 2,000,000 字节内的完整文字参与助手检索，后文可分页查看。需要后文参与回答时，按主题拆成小文件分别审核。大文件可上传完整替换版本；原已批准修订继续按原规则使用。服务器空间不足或有其他大文件在上传时，请按界面提示稍后再试。
3. 文件上传后会先解析。“刷新状态”可重新读取结果。显示“待批准”时，点“查看原文”逐段核对价格、范围、承诺等内容。
4. 点“批准并发布”。选择要纳入新版本的全部文件。已发布的原文默认保留。如果文件有新修订，可以选“保留已批准的第 N 次修订”或“批准新的第 N 次修订”。逐项核对后点“确认批准并发布”。
5. 发布后会显示“已批准”和“第几版已发布”。在助手向导中选择这一版，助手就能检索这批资料。

| 页面提示 | 含义与下一步 |
|---|---|
| 解析中、尚未审核 | 文件已上传，可稍后刷新 |
| 待批准 | 已解析，尚未纳入当前发布版；打开原文审核 |
| 已批准、第 N 版已发布 | 此文件已经进入该发布版。助手还需绑定相应版本 |
| 解析失败 | 检查编码、格式与文件内容，修正后重新上传 |
| 已撤回 | 该修订已禁止引用。依赖它的待发意图会被取消 |

**修改资料**时，在资料库目录的操作栏点“编辑资料库”可改名。点“管理文件”可查看文件。点文件旁的“编辑文件”可改标题、正文和来源。保存后需重新“批准并发布”，再在助手配置中选择新版本并发布。旧任务仍引用原先批准的版本。

**停用错误原文**时，点“撤回”并填写原因。已有新修订时，可展开“仍在当前发布版中的旧原文”查看或撤回旧修订。只删一份文件，在该文件所在行点“删除文件”。整库删除，在资料库目录的对应行点“删除资料库”。前者移除该文件的全部修订，后者连同库内文件一起移除。删除均需要确认，依赖相关原文的待发消息会被取消。

## 4. 创建与发布助手

### 用模板开始

在「助手管理」选择创建方式。点「从模板创建」能查看六种常用销售角色；点「我的模板」能找到自己保存的配置；点「创建助手」可以从空白开始。三种方式都进入现有的四步向导。

**例如创建新能源销售助手。** 选择「行业定制销售助手」→「使用此模板」。输入助手名称并选择本次产品。进入「角色设置」就能看到预填的身份、语气、筛选原则和工作目标，均可修改。想换一个模板时点「更换模板」。确认前页面会说明替换范围，取消会保留刚才的填写。

1. 在「角色设置」选择自己已验证的 DeepSeek 连接，做演示可明确选择「模拟模型」。模型调用会使用所选连接的额度。
2. 在「资料和工具」选择这款产品获批且有效的资料版本，再按需要勾选已授权的工具。“企业官网资料研究”可勾选并申请；其他标为「尚未接入」的推荐工具仍不能执行。
3. 在「人工接管」检查哪些情况必须转给真人。发布前检查会列出缺项。可以先点「保存草稿」，回来补齐后再点「检查并发布」。

模板保存的是创建助手时可复制的设置。它没有运行身份、客户会话或发送权。发布后，需要另行创建或启动任务，实际外发仍受原有权限和接管规则控制。六种内置模板涉及产品事实，都需要有效资料。

### 把常用设置留给自己

| 想做什么 | 工作台操作 |
|---|---|
| 自己做一个模板 | 「我的模板」→「新建模板」。填写名称、用途、场景和角色设置，核对工作范围、禁止事项和交接条件后点「保存模板」。退出后仍可再用。 |
| 从现有助手提取 | 打开**自己创建的助手**的详情 →「保存为我的模板」。选择当前草稿或指定发布版本。在预览里检查会保留的文字，把企业专有名称替换为「【产品】」等占位词，再填写简介和场景并保存。 |
| 修改或复制 | 在个人模板卡片的「更多操作」或详情页编辑、复制。在系统模板详情点「复制为我的模板」可建立自己的可编辑副本。 |
| 删除 | 在个人模板的「更多操作」或详情页点「删除」，核对后确认。以前由它创建的助手继续使用原先保存的配置。 |

个人模板仅本人可见。产品资料绑定、个人模型连接、实际工具权限、客户和聊天记录都留在原助手中。写在角色文字里的专有信息需要自己检查。下次套用时，按新产品和自己的账号重新选择资料与模型。

### 四步向导与版本

“助手管理”中可以按名称搜索，查看所属企业、产品、类型、当前版本、状态和更新时间。点击名称或“详情”可看配置。当前发布版另有草稿修改时，列表会显示“另有未发布修改”。

| 向导步骤 | 怎么填 | 例子或影响 |
|---|---|---|
| 基本信息 | 填助手名称，核对所属企业，选择产品和业务类型 | 名称可填“排班产品商务顾问”。企业销售和店铺客服有各自的接管规则。首次保存后产品和类型固定 |
| 角色设置 | “角色”说明以什么身份工作，“主要工作”说明日常职责，“沟通风格”决定语气，“目标”说明想达成什么 | 可以分别填“产品顾问”“了解客户排班方式”“专业、简短”“确认团队规模”。主要工作与目标共同写入工作说明 |
| 资料和工具 | 勾选产品已经发布且仍有效的资料版本；选所需工具；每行填一项可答内容或禁止承诺 | “查询客户本人的订单”仅限已核实归属的订单。“提交渠道回复”仍需通过统一发送检查。禁止项可填“保证交付日期” |
| 人工接管 | 勾选哪些信号需要真人处理，查看发布前检查结果 | 销售可勾“要求正式报价”“涉及合同或付款”；客服可勾“退款”“投诉”。要求真人、询问身份则按所选业务规则处理 |

**选择模型。** “角色设置”默认选择模拟模型，适合练习。选择 DeepSeek 后，下拉框只列你自己测试通过的连接。你创建的销售助手和客服助手可共用一条连接，各自选择可用型号。模型服务会按实际用量计费。客户消息渠道仍然模拟。

**管理连接。** 在“助手管理 → 我的模型连接”可改名、重新测试、更换密钥、查看引用、停用或删除。轮换沿用连接编号。停用前会列出受影响的助手。只要草稿或历史发布版仍在引用就无法删除。付费调用使用助手创建者的个人密钥。旧助手如果绑定过别人的连接，请改选自己的连接并发布，再用新版本建任务。

**保存草稿**允许稍后继续编辑。**发布助手**会校验资料和模型连接。新任务可以选这次发布的版本。已有任务继续使用原版本。若服务端提示修订冲突，请重新打开详情再编辑。

**停用助手**会阻止这位助手的新旧任务继续自动执行。页面要求确认并填写原因。查看错误时请先读具体提示，特别是“资料已撤回”“配置不完整”“没有操作权限”。

**删除助手**位于助手详情页，草稿和已发布助手都可以删除。确认后，助手和它的任务从管理列表移除。相关会话结束，仍可到“客户会话与任务”查看历史对话。

## 5. 客户会话与任务

在助手详情点“前往任务管理”可只看这位助手的任务。需要查看所有有权管理的任务时，打开“客户会话与任务 → 销售与接待任务”。任务列表可按状态和名称筛选。

| 按钮 | 什么时候用 | 点击后会发生什么 |
|---|---|---|
| 创建任务、启动任务 | 已发布助手，准备开始销售或接待 | 选择所需助手及版本，先建立待启动任务。启动以后后台才可领取工作 |
| 编辑任务 | 想改任务名称或工作备注 | 打开任务详情，点“编辑任务”。任务仍使用原助手和已选版本 |
| 删除任务 | 确定要从任务列表移除本项工作 | 确认后停止运转、取消待执行工作、关闭相关会话，保留历史。此助手的其他任务照常运行 |
| 建立会话 | 需要接待一位已核实客户 | 销售选择已启动任务与客户。客服可选择助手自动建立接待任务。已被其他活动会话占用的渠道不会列入选项 |
| 提交模拟来信 | 业务人员希望验证销售或客服行为 | 输入模拟客户的原话。合规运行时会产生执行记录；人工或暂停期间可能只保存来信 |
| 安排联系 | 销售业务需要拟定首信或到期跟进 | 选择动作。跟进需填写未来时间。引擎在实际执行前复核联系资格 |
| 暂停、恢复 | 暂时中止或继续一项任务 | 暂停后阻止自动发送；恢复会重新核对状态，人工接管与退订继续生效 |
| 停止任务 | 确定本任务已经结束 | 确认并填原因，永久结束当前任务；历史保留 |
| 纠正客户事实 | 坐席发现客户记忆有误 | 选择证据消息，填写正确值和原因。历史原话保留，下一轮按修订值处理 |

进入会话后先读“完整对话”。消息旁会标明是客户、助手草稿、助手回复还是人工回复。较长会话可点“读取后续消息”。右侧显示客户资料、摘要、重要事实及待处理事项；最近执行单独展示，工具调用和内部编号放在“高级信息”。

## 6. 人工接管与交回

1. 从“人工接管”找到客户，核对原始问题、转人工原因、已处理事项和最近发送状态。也可以从普通会话点“转人工”，写明原因。
2. 系统建立交接工单时就冻结自动发送。点“认领任务”后，当前坐席成为唯一人工负责方。
3. 点“人工回复”，填内容后提交。回复也经过渠道权限、退订、窗口和发送代次检查。若已有一条结果未知的发送，先请维护者核实回执。
4. 人工处理完成后，根据需要选择 **交回助手** 或 **结束会话**。交回要写明处理结果，系统重新核对停发条件。任务仍暂停时，会话仍保持暂停。交回不会立刻补发旧草稿。
5. 若选择结束，会保留历史对话。可以从已结束的会话详情回看处理记录。

| 发送状态 | 如何理解 |
|---|---|
| 未发送 | 本轮没有外发，例如索要正式报价后转人工 |
| 待发送、发送中 | 已有发送意图。请等待结果 |
| 平台已受理 | 渠道接受了请求。当前为模拟渠道，不能据此判断客户已经收到 |
| 发送结果待核实 | 是否已受理仍需对账。先核实回执，避免重复发送 |
| 已取消发送、发送失败 | 查看执行原因和会话状态，决定人工处理还是重新评估 |

有新执行记录时，总览会更新。会话和人工列表会提示刷新，详情可以点“刷新会话”。没有新信息时，请通过“最近执行”确认实际进度。
