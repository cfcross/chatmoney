# ChatMoney 团队部署与维护

本文按原有团队部署记录整理通用步骤。正式服务器地址、私有凭据、备份位置和历史运维命令由维护者另行保管。

## 服务与访问

团队使用 HTTPS 登录工作台。反向代理连接只监听回环地址的 API。普通 Worker 处理业务与索引，对练 Worker 和研究 Worker 分别领取自己的队列。PostgreSQL 保存业务数据和执行状态。检查服务组成与暴露端口时，以部署用 Compose 文件和实际服务状态为准。[服务配置](../../deploy/server/compose.yaml)

## 首次启动与升级

1. 给运行身份和迁移身份设置不同凭据。私有配置由部署者管理，API 和 Worker 使用同一个凭证加密主密钥。登录工作台后由管理员开通成员账号。
2. 记录现用镜像、数据库迁移版本、卷和配置文件，备份数据库及将被替换的文件。在独立库验证备份可读，并验证新旧版本的迁移路径。
3. 按现有部署配置执行 Alembic 迁移，启动 API 和相应 Worker。检查本机健康响应、HTTPS 登录、旧助手、资料和一个模拟任务。研究进度停在排队时，先检查研究 Worker 及来源有效期。
4. 回退前检查旧代码能否读取新结构。保留升级期间写入的数据，需要恢复备份时先安排写入窗口。仓库合并和生产发布由维护者分别决定。

独立开发机的安装、模拟数据和测试入口见[引擎运行说明](../architecture/ChatMoney_团队工作台与共享Agent引擎说明.md)。
