# ChatMoney V1.4：首个 ToB 真实只读工具开发与验收

> 历史版本记录。本文保留当时的测试口径。本次提交的结果见 [PR #1 修复记录](ChatMoney_PR1_合并前互查问题修复报告.md)。

日期：2026-11-15。入口：团队工作台 → 助手管理 → 本人销售助手 → 企业研究。**研究可以访问真实网站；没有任何向客户发送消息的入口。** 本轮用一家独立机构运营的公开测试站做了真实公网验收；没有取得或使用真实潜客名单、商家账号和付费模型密钥。

## 这次交付了什么

- **企业官网资料研究**（`company.profile_read`，工具版本 1.0）：由成员给定一个获准网页，读取少量静态业务资料，返回出处、读取时间、短摘录、缺失项、匹配解释和可编辑的联系草稿。
- 工作台提供“研究来源与授权”“企业研究”“我的研究记录”。管理员登记来源许可、审批或撤销；所有者发起、停止、重试、审核或保存研究。保存线索不会创建正式客户、会话、人工工单或发送记录。仅验收的来源不能转成正式销售线索。
- 官网、Brave Search、Alibaba.com、Amazon、1688 的取舍和可核验的一手资料见[选型终审](../research/ChatMoney_ToB第三方平台接入优先级终审.md)。本轮选择经明确许可的官网。搜索发现和已登录商家接口都未开启。

| 完整回归 | 原有 25 个测试及支持文件与修改前备份逐字节一致，原有 163 项全部保留。新增 **56** 项，最终 **219 passed / 0 failed / 0 skipped，用时 82.28 秒** |
| 新增范围 | [网络、提取和业务](../../tests/test_company_research.py) 50 项，涵盖公开地址／域名复核、重定向、robots、请求和大小限制、只读请求头、禁止跟踪链接、页面简介与主体事实、匹配规则及审批去重；[个人连接与隔离](../../tests/test_research_ownership.py) 2 项；[中断、撤回、模拟工具](../../tests/test_research_resume.py) 4 项。含模型响应不确定时不自动重试 |
| 原业务 | 模板、草稿／发布、个人连接、模拟及评测、报价交接、O7/O8 归属、会话／记忆、登录与角色、Worker 重启、资料审批及上传均在原有回归中 |
| 上传边界另测 | 本地真实行使上传入口：999,999,999 和 **1,000,000,000** 字节返回 202，后者的完整内容取回后 SHA-256 校验一致；1,000,000,001 字节返回 413。无残留中转文件，没有向团队服务器上传 1 GB 测试文件 |
| Edge 浏览器 | 使用本机安装的 Microsoft Edge 157.0.4341.46，通过工作台操作而非代替按钮直接造结果。检查 **1440×900、1280×720、1024×768、390×844**，未发现页面宽度溢出、主要按钮重叠或脚本异常。实际截图中发现的长英文账号越出侧栏已修正，浏览器另检查可见账号文字的边界。流程分别在本地独立环境与公网执行 |
| 费用界线 | 自动化测试只使用 HTTP 测试响应或受控页面；另做真实公网样站读取。离线 DeepSeek 接口测试核实使用了正确成员的凭证，来源未许可交给模型或使用者未确认费用会被拒绝。线上验收选择 `mock-local`，未花费成员的 DeepSeek 额度，未验收真实付费模型生成质量 |

**Edge 的五条实测路径：**

1. 成员用软件与企业服务模板创建助手，选模型和获批资料、勾选研究，完成多轮报价交接对练、审阅和提交。发布相同配置后，管理员核对候选配置、登记来源。成员申请后仍是待审批；管理员明确批准才可以用。
2. 成员选择来源和目标词，提交后由研究 Worker 执行。页面显示官网摘录、时间、匹配依据、产品资料和可编辑的草稿。
3. 待审批时直接提交得到 403；无管理员权限不能管理审批。另一成员／管理员不能阅读他人私有报告（404），管理员可以处理必要的授权元数据。
4. 工作台输入 `https://localhost/` 后被后端拒绝，没有产生研究任务。本地自动化另覆盖内网、保留地址、非标准端口、重定向和解析结果变化；没有对这些目标发起真实探测。
5. 修改草稿、审核、保存测试线索、刷新、再读报告，内容仍在。公网临时验收空间保存前后实际核对：1 个获准来源、1 项授权、1 个研究结果、1 条**测试**线索；正式客户、订单、会话、消息、普通销售任务、人工工单和发送台账全部为 0。核验后只清理专用验收空间，正式成员的资料没有被删除。

本轮早期本地浏览器验收遇到登录页面尚未就绪；修正验收脚本等待登录完成后重跑通过。早期 215 项通过是中间结果；核对公网样本发现不能将网页简介当作企业经营证明，并补齐页面和链接的禁止跟踪处理，增加四项验收，以上数字来自最终版。

## 实际外网读取

第一次选用公开练习书店。开发电脑解析为非公网地址，工具在 HTTP 请求前停止；服务器独立尝试时触发页面读取限制（`RESTRICTED`），没有继续取证，没有改换代理、浏览器或放宽规则。

最终样本站为 **[TestingURL](https://testingurl.dev/)**。站方明确邀请爬虫和 HTTP 客户端在其练习页验证；选择[固定的虚构商品资料页](https://testingurl.dev/scraping/structured-data/product-json-ld)，来源登记为**仅验收、可暂存短摘录、无外部模型处理、无联系资格**。没有使用真实潜客资料。最终公网运行北京时间 **20:20:32** 取证：

| 实际请求 | 响应 | 验证 |
|---|---|---|
| 同站 `/robots.txt` | 200，194 字节 | 实际检查网站读取规则 |
| 指定商品页（只此一页） | 200，49,880 字节 | 提取到站方展示的虚构笔记本型号 **Vertex Air Laptop 107**，与原页的产品声明一致；正文没有被当作指令执行 |
| 匹配 | 100/100，覆盖率 100% | 仅设置“主要产品含 Laptop”这一项，因此只能说明这一条吻合。**不能据此认定这家企业适合购买我们的产品**。没有企业法人、预算、决策人、购买意向或成交概率 |
| 草稿 | 有草稿，可改，未发送 | 以该型号为开头，引用已批准的测试产品资料“支持排班”，请对方核实场景。人工通过页面改为验收专用文字，保存后重新读取验证。未发现经核实的商务联系入口 |

验收证据记录真实请求字节数、时间、证据对应关系、浏览器尺寸、静态资源校验值与清理前计数；回归输出、公网 Edge 操作入口。长期移交的是技术验收指标和短事实，不附外部网页全文、第三方账号、登录会话或测试凭证。

## 使用边界与下一步

日常操作、如何判断有无联系资格，以及停止、重试、撤回见[中文使用指南](ChatMoney_Agent中文管理界面使用指南.md)。真实企业需先核实访问、留存和内部销售研究用途；对外模型处理、记录通用联系页面也须另行许可。只支持标准 HTTPS 的静态页面；登录页、脚本渲染、站方强制使用不支持的压缩、条款不明或缺少留存权时，不切换浏览器继续读取。当前不采集或猜测个人邮箱、电话；也不抽取企业通用邮箱，只可按许可记录官方合作页面链接。

若需要主动发现企业，下一阶段优先评估 Brave Search 的预算、账号和存储条款；先产生候选官网，确认来源许可后再复用现有研究工具。Alibaba.com 要先取得具体的官方只读接口和商家授权；Amazon 的订单消息接口不得用于陌生品牌营销；1688 要先取得书面许可并完成必要评估。它们都未在本轮接入。
